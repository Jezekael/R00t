# XSS (Cross-Site Scripting)

**Cross-site scripting (XSS)** is a web security vulnerability that enables an attacker to manipulate a vulnerable website to return malicious JavaScript to users. Attackers can use malicious code to compromise a victim's interaction with the application fully.
